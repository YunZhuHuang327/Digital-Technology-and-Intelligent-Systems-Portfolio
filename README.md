# Digital-Technology-and-Intelligent-Systems-Portfolio

This repository is a portfolio of digital technology and intelligent systems projects, featuring innovative applications developed using Arduino. It highlights my skills in embedded systems, sensor integration, and IoT solutions.

## Featured Projects

- **Ultrasonic and Infrared Autonomous Car**  
  An Arduino-powered self-driving car that navigates and avoids obstacles using ultrasonic and infrared sensors.

- **LINE-Connected Baby Sensor**  
  A smart baby monitoring device that detects the baby’s condition and sends real-time notifications via LINE, suitable for smart home scenarios.

- **Infrared Remote-Controlled Piano**  
  An interactive electronic piano that can be operated remotely via an infrared controller, combining music with creative technology.
